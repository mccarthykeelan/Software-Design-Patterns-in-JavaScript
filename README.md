# JavaScript Design Patterns

A collection of common software design patterns implemented in JavaScript.

This repository contains examples, explanations, and practical implementations of design patterns used to write cleaner, more maintainable, and scalable applications.

## Patterns Covered

### Creational Patterns

- Singleton
- Factory
- Abstract Factory
- Builder
- Prototype

### Structural Patterns

- Adapter
- Decorator
- Facade
- Proxy
- Composite

### Behavioral Patterns

- Observer
- Strategy
- Command
- Iterator
- State
- Template Method

Each pattern includes:

- Explanation of the problem it solves
- JavaScript implementation
- Code comments
- Common use cases
- Advantages and disadvantages
